CouncilTrack AI — Complete Functionality Walkthrough

A centralized campus governance, daily & weekly goal tracking, evening reflection, AI performance analytics, and student feedback management platform.

3 Dedicated Portals Daily & Weekly Goals Evening Reflections AI Monthly Reports Real-Time Updates Public Student Voice

1. What is CouncilTrack AI?

CouncilTrack AI brings all campus council operations onto a single structured platform. Instead of tracking daily tasks in scattered notebooks or chat groups, council coordinators set clear morning goals, log mandatory evening reflections, track weekly/monthly progress, and resolve student feedback transparently—while campus leadership monitors everything in real time.

Admin Portal
Route: /admin/login

Full campus oversight: manage councils, assign coordinators, monitor daily goals, review analytics, and oversee feedback resolution.

Council Member Portal
Route: /council/login

Coordinator workspace: set daily & weekly goals, submit evening reflections, view progress trends, and handle council-specific feedback.

Public Student Feedback
Route: /feedback

Open access with zero login required. Any student can submit suggestions, feedback, or grievances directly to the relevant council.

2. End-to-End Daily Workflow

The platform is built around a simple, high-accountability daily and weekly rhythm:

1. Morning Goals Coordinators set daily priorities & weekly milestones
→
2. Execution & Feedback Councils work on tasks & review student submissions
→
3. Evening Reflection Mark goals done or log impediment reasons & learnings
→
4. Live Analytics & AI Dashboards update & AI scores monthly performance

3. Council Member Portal Features (/council/*)

Once a coordinator signs in at /council/login using their assigned council email/handle and password, they get access to:

Module / Route What It Does
Dashboard
/council/dashboard		 Displays today's active goals, completion rate, reflection status, quick-action shortcuts, and recent council activity at a glance.
Daily Goals
/council/goals		 Create, edit, and track daily tasks with status updates (Pending, In Progress, Completed, Incomplete).
Weekly Goals
/council/weekly-goals		 Plan broader weekly milestones and track multi-day deliverables across the week.
Evening Reflection
/council/reflection		 End-of-day self-audit. Completed goals are summarized automatically; incomplete goals require an impediment reason, plus key learnings and next steps.
Weekly Progress
/council/weekly-progress		 Visual charts and metrics showing weekly goal completion rates, consistency across weekdays, and reflection compliance.
Monthly Progress
/council/monthly-progress		 Month-level performance summary, historical trends, and AI-evaluated strengths, improvement areas, and recommendations.
Council Feedback
/council/feedback		 Inbox of student feedback/complaints routed specifically to that council, allowing coordinators to track and update resolution status.
Profile & Settings
/council/settings		 Update display name, custom login user ID/handle, email address, and account password.

Admin Dashboard
/admin/dashboard		 Executive summary of all campus councils—live goal completion percentages, active vs. pending reflections, and open student feedback counts.

Feedback & Grievances

5. Public Student Voice Portal (/feedback)

  • Zero-Friction Access: Available directly from the home page without requiring any login or account registration.
  • Targeted Routing: Students select the relevant campus council and submit suggestions, appreciation, or complaints.
  • Instant Visibility: Submissions appear immediately in the target council's Feedback inbox and the Admin Feedback console for action.

6. Intelligence, Automation & Technical Architecture

AI Performance & Scoring Engine

Evaluates monthly coordinator performance across 5 dimensions: Goal Score, Consistency Score, Reflection Score, Feedback Score, and Improvement Score. Generates qualitative strengths, improvement areas, and actionable recommendations (supports Gemini, OpenAI, or built-in heuristic analysis).

Real-Time Sync & Notifications

Socket.io pushes live updates to Admin and Council dashboards whenever goals, reflections, or feedback change. Discord Webhooks and scheduled background jobs automate daily goal reminders, meeting alerts, and monthly report generation.

Dual-Mode Storage Engine

Supports both Local Storage (counciltrack_store.json) for fast local/offline setups and Google Sheets API (8-worksheet cloud database) for cloud-synced deployments—no code changes required to switch.

Security & Role Isolation

Uses JWT authentication, bcrypt password hashing, rate limiting, and strict route-level role guards so Admin tools and Council workspaces remain cleanly separated.

Tech Stack Summary: React 19 + Vite + Tailwind CSS + Recharts (Frontend) • Node.js + Express + Socket.io + JWT + bcrypt (Backend REST API /api/v1) • Google Sheets / JSON Store + Discord Webhooks + AI Service.
