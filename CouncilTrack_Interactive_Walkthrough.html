🏛️ 14 Official Campus Councils 👥 25 Designated Coordinators 🛡️ Role-Based Access Control ⚡ Real-Time WebSockets 📊 Automated PRD Formulas 📢 Discord Webhooks Integrated

🎯 Yeh Project Kya Hai aur Kaise Kaam Karta Hai?

💡 Aasan Hindi / Hinglish Mein Samajhein:

CouncilTrack AI NavGurukul Dantewada campus ke liye banaya gaya ek digital management platform hai. Pehle campus councils (jaise Discipline, Workout, English, Culture, IT etc.) apne daily task aur student problems ko manually ya registers mein track karte the.

Is platform se:
1. Subah (Morning): Har Council Coordinator apne daily goals set karta hai.
2. Shaam (Evening): Coordinator apni Evening Reflection bharta hai (Kaunsa goal complete hua, kaunsa incomplete raha aur kyu).
3. Students: Bina kisi login ke direct website par aakar apni complaints ya feedback de sakte hain.
4. Admin: Campus Team sabhi 14 councils ki live performance, weekly consistency aur complaints ek single dashboard par monitor kar sakti hai.

Role 1

🛡️ Campus Admin

Campus Leadership & Facilitators jo sabhi councils ko manage karte hain.

  • Members ko add/edit/deactivate karna.
  • Sabhi 14 councils ke daily goals check karna.
  • Goal status audit trail (Kisne status kab change kiya).
  • Private Admin Notes ke saath student complaints solve karna.
Role 2

🎯 Council Coordinator

25 Chune hue coordinators jo apne council domains ko lead karte hain.

  • Subah daily goals set karna (Priority + Target Outcome).
  • Shaam ko mandatory Evening Reflection submit karna.
  • Incomplete goal par compulsory reason likhna.
  • Apne council ki weekly/monthly consistency track karna.
Role 3

🎓 Campus Student

Dantewada campus ke sabhi students (Zero login friction).

  • Direct /feedback link kholna.
  • 14 Councils mein se kisi bhi council ko select karna.
  • Suggestion, Feedback ya Complaint likhna.
  • Optional: Apna naam aur contact dena ya Anonymous rehna.

⏱️ Daily Operating Cycle (Council Members ka Daily Routine)

  1. 08:30 AM — Morning Goal Setting (`/council/goals`)

    Coordinator login karke apne council ke 2 se 4 daily goals banata hai. Priority set karta hai (HIGH, MEDIUM, LOW) aur expected outcome likhta hai.

  2. Day Time — Council Execution

    Campus mein coordination activities chalte hain (e.g., Workout session, English class prep, IT lab setup).

  3. 08:30 PM — Evening Reflection (`/council/reflection`)

    Mandatory reflection portal: Aaj ke goals ko check kiya jata hai. Jo goal pura hua use Completed ✓ karte hain. Agar koi goal adhura reh gaya, toh system mandatory reason mangta hai (e.g. "Power cut in lab").

  4. Automatic Analytics Calculation

    System formula (Completed / (Completed + Incomplete)) * 100 se automatically weekly aur monthly progress calculate karke Admin aur Coordinator dashboards update kar deta hai.

🔑 Where and How to Update Admin ID, Email & Password

⚡ Seedhe Jawab (Quick Summary):

Aap Admin ka email, ID ya password 3 alag tareeqon se update kar sakte hain:
1. Sabse Aasan (Via Web UI): Web Portal ke andar /admin/members page par jakar Admin User ko Edit karein.
2. Direct Data File (Local Mode): counciltrack-ai/backend/data/counciltrack_store.json file kholkar USR_001 ke email aur password ko update karein.
3. Google Sheets Mode: Apni Google Sheet ke `Users` tab mein jakar Row 2 ko update karein.

Tareeqa 1: Frontend Admin Portal Se Update Karna (Recommended)

  1. Admin Portal par login karein:
    URL: http://localhost:5173/admin/login
    Email: admin@counciltrack.org | Password: Admin@123
  2. Left sidebar menu se "Members" (/admin/members) par click karein.
  3. Members list mein sabse pehla user "Admin User" (ID: USR_001) dikhega.
  4. Right side mein diye gaye "Edit (Pencil Icon)" par click karein.
  5. Modal khulega jisme aap:
    • Email / Login ID: Naya admin email daal sakte hain.
    • New Password: Naya password daal kar Save karein (System automatically bcrypt se hash karke secure kar dega).

Tareeqa 2: Local Database File (`counciltrack_store.json`) Se Update Karna

Agar server locally chal raha hai, toh data is JSON file mein persist hota hai:

counciltrack-ai/backend/data/counciltrack_store.json { "Users": [ { "userId": "USR_001", "name": "Admin User", "email": "admin@counciltrack.org", /* <-- Yahan naya email likhein */ "passwordHash": "$2b$10$o0O6k.vZ.7Ft/Oz/yosx9uZ731QobdnCMQntp.XHJxJHW7w3RdkW.", "role": "ADMIN", "position": "Administrator", "status": "ACTIVE" }, ... ] }

Tareeqa 3: Backend Controller Mein Fallback Master Passwords & Aliases

Backend ke authController.js mein safety aur testing ke liye convenience logins configured hain:

counciltrack-ai/backend/src/controllers/authController.js (Lines 19-20 & 56-60) // 1. In Identifier Aliases: if (identifier === "admin" && uRole === "admin") return true; if (identifier === "admin@navgurukul.org" && uRole === "admin") return true; // 2. In Fallback Admin Passwords: if (userRole === "ADMIN") { if (password === "admin@navgurukul.org" || password === "Admin@123" || password === "admin123") { isMatch = true; } }

💡 Tip: Agar aap fallback passwords badalna ya remove karna chahte hain, toh aap seedhe authController.js mein lines 56-60 modify kar sakte hain!

⚙️ System Architecture & 8-Worksheet Database Model

💾 Dual-Storage Engine:

Backend mein Dual-Mode Storage Engine (`sheetsService.js`) implement kiya gaya hai.
• Agar GOOGLE_SHEET_ID aur credentials present hain, toh direct Google Sheets API se sync karta hai.
• Local development ya testing ke waqt bina kisi setup ke zero-friction local JSON storage (`data/counciltrack_store.json`) use karta hai.

The 8 Database Worksheets

1. `Users`

Admin & 25 Coordinator accounts with bcrypt hash, roles (ADMIN/COUNCIL), and status.

2. `Councils`

All 14 Campus Council entities, descriptions, and active status.

3. `Goals`

Daily goals with Priority, Target Date, Status (PENDING/COMPLETED/INCOMPLETE), and Incomplete Reason.

4. `Reflections`

Daily evening reflections containing achievements, challenges, learnings, and improvements.

5. `Student_Feedback`

Public complaints & suggestions with status (NEW/UNDER_REVIEW/RESOLVED) and private admin notes.

6. `Goal_History`

Immutable audit log of every goal status transition (who changed it, oldStatus, newStatus, timestamp).

7. `Audit_Logs`

System-level activity tracking for account creation, council updates, and sensitive mutations.

8. `Settings`

Dynamic campus configuration, curfew timings, and platform parameters.

PRD Standard Automated Progress Formula

Pending goals ko denominator se exclude karke strictly finalized goals par percentage calculate hoti hai:

Progress Rate (%) = (Completed Goals / (Completed Goals + Incomplete Goals)) * 100

🔔 Discord Webhook Integration & Live Alerts

Webhook Setup Steps:

  1. Apne Discord server par jaayein ➔ Channel Settings ➔ Integrations ➔ Webhooks.
  2. New Webhook banayein aur Webhook URL copy karein.
  3. counciltrack-ai/backend/.env file mein paste karein:
